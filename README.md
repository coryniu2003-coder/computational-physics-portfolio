# Computational Physics Portfolio

This repository contains small computational physics projects rewritten as public, reproducible Python examples.

It is intended as a lightweight coding foundation portfolio alongside larger scientific software projects.

## Projects

## Diatomic Morse Potential

`diatomic_morse/` simulates a one-dimensional diatomic molecule under a Morse potential.

Demonstrates:

- Force and potential implementation
- Numerical time integration
- Object-oriented Python
- CLI-style workflow

## Solar System N-Body Simulation

`solar_system_n_body/` simulates a simplified gravitational N-body system using a velocity-Verlet style method.

Demonstrates:

- Vector mechanics
- Numerical integration
- Data-driven initial conditions
- Basic simulation design

## Setup

Set up a virtual environment and install the lightweight dependencies:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
